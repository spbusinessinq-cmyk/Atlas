FEATURE 1 — DOCUMENT ENTITY EXTRACTION

When a document is uploaded into the DOCUMENT VAULT, ATLAS should automatically analyze the text and extract potential entities.

Entity types to detect:

Person
Organization
Government Agency
Company
Nonprofit
Location
Program
Facility
Financial Institution

Implementation steps:

• Extract text from uploaded PDFs using pdf-parse
• Run Named Entity Recognition using spaCy, compromise.js, or a lightweight NLP model
• Generate candidate entities

For each detected entity:

Create a suggested entity object with:

name
entity_type
confidence_score
document_source
position_in_text

These should appear in the UI as:

"ENTITY DETECTION RESULTS"

The investigator can approve or reject each detected entity before it enters the ENTITY REGISTRY.

FEATURE 2 — MONEY FLOW TRACKING

ATLAS must support tracing financial flows across entities.

Add a new module:

FLOW TRACE

Database table:

money_flows

Fields:

id
source_entity_id
destination_entity_id
amount
currency
date
description
supporting_document_id
confidence_level

Money flows should appear in:

• Case dashboards
• Entity pages
• Timeline entries
• Graph visualization

Example chain:

Federal Grant → LA County → LAHSA → Nonprofit Shelter Org → Hotel Program

Each step should be stored as an individual flow record.

ATLAS should be able to visualize this as a **financial chain graph**.
