========================================================

Problem:
Some web-ingested documents still resolve to Google News wrapper or partial snapshot content.

This breaks:
- entity detection
- timeline extraction
- money extraction
- auto-approval
- seeded case usefulness

Fix this first.

Requirements:

1. Detect wrapper / redirect / metadata-only pages.
Examples:
- Google News wrappers
- feed wrappers
- pages with almost no article body
- metadata-only snapshots

2. Resolve the real original source URL whenever possible.

3. Extract article body only from real source content.

4. If extraction fails:
- mark the doc as EXTRACTION_FAILED or EXTRACTION_PARTIAL
- do NOT run normal entity extraction on wrapper text
- do NOT create junk entities like "Google News"

5. Add a blocklist / suppression rule so wrapper-only values cannot become entities.

6. Update the analyzer so entity extraction only runs on valid extracted article text.
