1. GRAPH NODE ACTIONS
==================================================

When I click a node in LINK ANALYSIS, the right dossier panel must include operator actions:

- REMOVE FROM GRAPH
- DELETE ENTITY FROM CASE

- REJECT / PURGE ALL PENDING MENTIONS FOR THIS ENTITY IN THIS CASE

- DELETE ENTITY FROM CASE = remove entity + mentions + case relationships for that case

Must update graph immediately without reload.
