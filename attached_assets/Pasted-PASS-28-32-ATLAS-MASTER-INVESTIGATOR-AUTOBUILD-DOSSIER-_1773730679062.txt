PART 7 — AUTO-BUILD GRAPH COMPILER
==================================================

This is the big one:
When a case seeds successfully, ATLAS must auto-build a starter case graph from confidence.

The graph compiler must:
- take promoted entities
- take strong labeled relationships
- take repeated associations
- take title/dek/lead evidence
- take document support count
- take role-bearing strength

Build a starter graph automatically with:
- 3–8 promoted core entities max for first build
- no junk nodes
- no weak nodes promoted just to fill space
- no malformed names
- no generic one-word people
- no article-title fragments

Node priority:
1. seed target / main target
2. strongest related institutions
3. strongest related associates
4. strongest role-bearing organizations
5. strongest confirmed locations only if central

Add graph quality states:
- STRONG BUILD
- PROVISIONAL BUILD
- RECOVERED BUILD
- WEAK BUILD
- FAILED BUILD

Rules:
- STRONG = multiple usable docs + multiple clean promoted entities + real links
- PROVISIONAL = some core entities but limited confirmations
- RECOVERED = second-pass rescue built the graph
- WEAK = too much ambiguity or contamination
- FAILED = no viable starter graph
