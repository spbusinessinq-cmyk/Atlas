PART A — AUTO-CASE COMPILER (CORE UPGRADE)
==================================================

--------------------------------------
A1 — EVIDENCE SCORING SYSTEM
--------------------------------------

Score documents using:
- relevance to seed intent
- keyword overlap with seed + top entities
- position of signal (title/dek > body > tail)
- presence of multiple entities
- presence of timeline markers
- presence of financial signals

Output:
- rankedDocs (top 3–5)

--------------------------------------
A2 — ENTITY RANKING
--------------------------------------

Rank entities using:
- mention frequency across docs
- number of supporting documents
- average/max confidence
- role-bearing signals (organization, official, funding entity)
- de-weight weak single-doc mentions

Output:
- primaryEntities (top 3–6)
- secondaryEntities (optional)

--------------------------------------
A3 — TIMELINE PRIORITIZATION
--------------------------------------

From timeline_entries:
- group by date
- collapse duplicates
- prioritize:
  - earliest
  - latest
  - high-signal events (mentions entities or money)

Output:
- topTimelineEvents (max 5–8)

--------------------------------------
A4 — FINANCIAL SIGNAL PRIORITIZATION
--------------------------------------

From financial_signals:
- normalize amounts
- rank by:
  - magnitude
  - relevance to seed entities
  - repeated mentions across docs

Output:
- topFinancialSignals (max 3–5)

--------------------------------------
A5 — CASE BRIEF GENERATION
--------------------------------------

Generate a structured case brief using ONLY ranked items.

Sections:
- WHAT THIS CASE IS
- PRIMARY ACTORS
- PRIMARY ORGANIZATIONS
- KEY EVIDENCE (top docs with short explanation)
- TIMELINE (bullet format)
- MONEY FLOW (bullet format)
- CURRENT STATE / WHY IT MATTERS
- KNOWN GAPS (if weak)
- SUGGESTED NEXT QUERIES

STRICT RULES:
- do NOT include low-confidence junk
- do NOT include nav/artifact entities
- do NOT hallucinate missing info
- if weak → say weak
- if no money → say no financial signals found
- if no timeline → say no date-anchored events found
