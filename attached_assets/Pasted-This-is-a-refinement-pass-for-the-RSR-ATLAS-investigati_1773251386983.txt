WORKSPACE PHILOSOPHY

ATLAS is an investigative workspace.

The investigation map (Link Analysis graph) must remain the central focus.

Documents, notes, and entity registries should behave like tools that open when needed, not panels permanently occupying space.

Avoid overlapping windows or multiple panels fighting for attention.

Preserve the existing 3-panel structure but refine behavior.

LEFT PANEL
Case navigation rail.

Contains:
Overview
Link Analysis
Entity Registry
Document Vault
Temporal Trace
Flow Trace
Analyst

This panel remains fixed and narrow.

CENTER PANEL
The investigation canvas.

Default content:
Link Analysis graph.

The graph should occupy the majority of the workspace.

No extra panels should appear over the graph unless explicitly opened.

RIGHT PANEL
