ATLAS STABILITY & WORKFLOW PASS

You are improving the RSR ATLAS investigation platform. Do NOT redesign the UI. This pass focuses only on stability, fixing broken behavior, and making the investigation workflow usable.

The current system mostly works but several issues exist with document handling, upload pipeline, layout clutter, and workflow clarity.

Implement the following fixes carefully.

--------------------------------------------------

1. FIX DOCUMENT SYSTEM (CRITICAL)

Documents must support three separate actions.

SELECT
Clicking the document title or row should:
- highlight the row
- open the Document Inspector in the right panel
- populate inspector with:
  title
  source
  ingest date
  case reference
  file type
  analysis status

SELECT should NOT attempt to load the file.

VIEW
The VIEW button must:
- open the document in the center panel preview
- if file type = PDF → render using embedded PDF viewer
- if file type = text → render formatted text
- if unsupported → show download option

The preview replaces the center workspace temporarily.

Add:
Close Preview
Return to Case Workspace

DOWNLOAD
The DOWNLOAD button must bypass the frontend router.

Currently downloads lead to:
Restricted_Area / 404

Fix by:
- returning the direct file URL
- triggering a normal browser download
- do NOT route through the app.

--------------------------------------------------

2. FIX UPLOAD PIPELINE

Verify and correct document ingestion flow.

Upload → Save file → Save metadata → Attach to case.

Ensure these fields store correctly:

file_path
file_name
file_type
case_id
ingest_date
source

After upload:
- document appears immediately in Document Vault
- row is clickable
- analyze button works.

3. VERIFY ANALYSIS PIPELINE

Approve / Reject buttons.
